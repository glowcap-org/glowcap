# conformance/episode-audit

Audit launcher for Episode output generated by the accountability-on-Goblins
worked example. It is application-layer evidence for accountability adapter
design, not a reference for the glowcap wire protocol.

## Running

Generate accountability output first:

```sh
( cd conformance/accountability-on-goblins && racket racket/kernel.rkt )
```

Then audit it:

```sh
bash conformance/episode-audit/run.sh
```

## Posture

- The audit reads generated output from
  `conformance/accountability-on-goblins/.data/`.
- `Episode` is host/application evidence and stays outside the Zig protocol
  core. No glowcap layer owns Episode vocabulary.
