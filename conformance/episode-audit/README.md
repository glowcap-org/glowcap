# conformance/episode-audit

Audit launcher for Episode output generated by the accountability-on-Goblins
worked example. It is application-layer evidence: useful for accountability
adapter design, not a pancake wire-protocol oracle.

## Running

Generate accountability output first:

```sh
racket conformance/accountability-on-goblins/racket/kernel.rkt
```

Then audit it:

```sh
bash conformance/episode-audit/run.sh
```

## Posture

- The audit reads generated output from
  `conformance/accountability-on-goblins/.data/`.
- `Episode` is host/application evidence. Keep it outside the Zig protocol core
  unless a future adapter explicitly owns that layer.
