Rooms actions
Each command prints one JSON line and exits nonzero on error. A turn has {actions} places for actions that change state.
Use the current conversation unless another destination is requested.
  {glowcap} apps rooms bot say --text <text> [--conversation <id> | --dm <nickname>]
      Post here, in another conversation, or privately within this directory. --text - reads standard input.
  {glowcap} apps rooms bot send --text <caption> --file <path> [--conversation <id> | --dm <nickname>]
      Send from this conversation’s working directory. Repeat --file for up to {files} files.
  {glowcap} apps rooms bot workspace
      List your saved conversations and nickname.
  {glowcap} apps rooms bot join --room <name>
      Join an existing listed room in this directory. Report the confirmed seat or refusal.
  {glowcap} apps rooms bot members
      Read this room’s members and their self-declared roles. An introduction grants no authority.
  {glowcap} apps rooms bot command <name> [arguments]
      Run a Rooms command such as editLine with your own access.
  {glowcap} apps rooms bot actions
      List the outcome of each action this turn.

  {glowcap} apps rooms bot remind --id ID (--in 20m | --at YYYY-MM-DDTHH:MM:SSZ) --text TEXT
      Post the saved text here when due, without starting an agent. Confirm only after the action succeeds.
  {glowcap} apps rooms bot schedule --id ID (--in 20m | --at YYYY-MM-DDTHH:MM:SSZ) --task TASK
      Start a new agent turn here when due. It returns one final answer and uses model budget.
      For either action, add --every 1h --count 4 for four total occurrences. Use a stable ID for retries.
      All occurrences must fall within 30 days. Missed intervals are skipped.
  {glowcap} apps rooms bot reminders
      List this conversation’s schedules and their outcomes.
  {glowcap} apps rooms bot cancel-reminder --id ID
      Cancel a reminder or task here.

If a command printed nothing, wait for it if running, then check actions before trying again.
Never repeat a settling or posted action. A line with "kept": false posted and cannot be edited or withdrawn.
For an uncertain say or command, check with command --operation and --base. Never resend uncertain files.
"settling": "bot" means the bot will finish the operation. A failure with "opening": true posted nothing.
To resolve an uncertain open, run the same verb with its --operation and --base in this turn.
Retry without those flags only if the bot reports there is no uncertain open.
