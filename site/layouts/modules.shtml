glowcap is one library, but it reads as a stack of small modules. Each one rests on the modules below it and may import only downward, so a layer's name tells you what it owns before you open the file. Teal is the sans-io protocol core. Neutral layers rest on the core without being part of it and do no I/O: the local actors, the Host that serves them, and Loam, which keeps them across restarts. Amber is where I/O, the C boundary, and the other languages live.
